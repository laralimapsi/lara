# Elementos — Lara Oraculista (biblioteca oficial)

15 elementos dourados escolhidos, com textura de folha de ouro e brilho suave.

- Catálogo: `catalogo-1-estrelas-sol-luas.png`, `catalogo-2-molduras-adornos.png`
- `png/metalico/` → para fundos roxo, verde e petróleo (Dourado Metálico)
- `png/velho/` → para o fundo pergaminho (Dourado Velho)
- `svg/` → mesmos elementos em vetor
- PNGs com fundo transparente, 1200 px no lado maior

**Estrelas, sol & luas:** brilho, explosão estelar, estrela vintage, lua e brilho, sol com lua, aurora, lua em órbita, luas gêmeas, lua envolta em ramos.
**Molduras & adornos:** portal em arco, guirlanda de folhas, moldura de carta, rosa dos ventos, talismã vertical, divisor botânico.
