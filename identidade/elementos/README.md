# Elementos — Lara Oraculista

Biblioteca de 25 elementos vetoriais, sempre em dourado (somente elementos, nunca tipografia).

- `svg/metalico/` e `png/metalico/` → para fundos roxo, verde e petróleo (Dourado Metálico)
- `svg/velho/` e `png/velho/` → para o fundo pergaminho (Dourado Velho)
- PNGs com fundo transparente (1200 px no lado maior), prontos para subir no Canva.
- Catálogo visual: `catalogo-1-natureza.png` … `catalogo-4-divisores.png`

## Regras de uso
- Use 2 a 4 elementos por arte, misturando 1 folhagem + 1 símbolo místico + 1 divisor/moldura.
- Folhagens nos cantos (superior esquerdo e/ou inferior direito), como na identidade original.
- Dourado Metálico nos fundos escuros; Dourado Velho no pergaminho.
- Nunca usar os dourados em textos.
